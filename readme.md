Bank Management System
A database-driven banking desktop application built in Python with MySQL and Tkinter, supporting core banking operations through a graphical interface.
Features
	•	Account creation, search, update, and deletion (full CRUD)
	•	Deposits and withdrawals with real-time balance updates
	•	Loan issuance with simple interest calculation, and loan repayment
	•	Login authentication to restrict access to the system
	•	Transaction data stored and retrieved via a relational MySQL schema
Tech Stack
	•	Python (Tkinter for GUI)
	•	MySQL (relational schema for accounts and loans)
	•	mysql-connector-python
